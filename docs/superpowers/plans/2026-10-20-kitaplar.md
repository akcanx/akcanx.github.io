# Kitaplar Sekmesi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Basılı kitapları tanıtan, yedi satış platformuna yönlendiren, menüde gizli bir Kitaplar sekmesi: `/kitaplar/` vitrini, `/kitaplar/kitap-adi/` kitap sayfası, panelde Kitaplar ekranı; üç örnek kitap.

**Architecture:** Kitaplar `D.books` koleksiyonu (dizi sırası = vitrin sırası), podcast serileriyle aynı desen: veri ve geçiş `store.js`'te (veri sürümü 5, örnek sürümü 6), sayfalar `render.js`'te (podcast vitrininin ızgarası 2:3 kapakla), panelde seriler ekranı ortak bir sıralı liste ekranına dönüştürülüp kitaplarda da kullanılır.

**Tech Stack:** Saf HTML/CSS/JS, Node 22+ (`build.js`, `node --test`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-20-kitaplar-design.md`

## Global Constraints

- Bağımlılık yok; testler `node:test` ile `tests/` altında (`tests/yukle.js` yardımcısı mevcut).
- Türkçe metin ve yorumlar; dosyaların mevcut üslubu korunur.
- Durumlar: `yayinda` → "Yayında", `onsiparis` → "Ön sipariş", `yakinda` → "Yakında" (vitrin kartında yalnızca "Ön sipariş" ve "Yakında" etiketi).
- Biçimler: `karton` → "Karton kapak" (schema `Paperback`), `ciltli` → "Ciltli" (`Hardcover`), `ekitap` → "E-kitap" (`EBook`), `sesli` → "Sesli kitap" (`AudiobookFormat`).
- Platform sırası ve adları: amazon "Amazon", dr "D&R", kitapyurdu "Kitapyurdu", idefix "Idefix", bkm "BKM Kitap", hepsiburada "Hepsiburada", trendyol "Trendyol". Yalnızca `Store.isProfile` geçen adresler gösterilir.
- Sayfa ayarı varsayılanları: `title` "Kitaplar", `eyebrow` "Kitap · Basılı ve yayımlanmış", `tint` `#4A3A1E`.
- Menü öğesi: `{ label: 'Kitaplar', type: 'books', visible: false }`; menü türü `books` → `kitaplar`.
- Örnek kitap kimlikleri `kitap-1`, `kitap-2`, `kitap-3`; `kitap-3` durumu `onsiparis`.
- Her görev sonunda `node --test tests/` yeşil, `node --check` temiz.

## Review Focus

1. **Gizli menü + yalnızca örnek kitaplar** → yayında `/kitaplar/` sayfası, site haritası girdisi ve `llms.txt` bölümü olmamalı. → Task 2 `kitap-rotalari-gizli-menu`.
2. **Platform adresi ana sayfa / boş / bozuk** (`https://www.amazon.com.tr/`, ``, `amazon`) → düğme çıkmamalı; hiç geçerli adres yoksa "Yakında satışta" notu. → Task 2 `kitap-satin-alma-dugmeleri`.
3. **Asgari kitap** (yalnızca ad) → kart ve sayfa `undefined/null/NaN` yazmamalı, künye boş satır basmamalı. → Task 2 `asgari-kitap`.
4. **Kullanıcı menüden Kitaplar öğesini silmiş** → geçiş onu yeniden eklememeli (sürüm 5 bir kez). → Task 1 `kitap-menu-bir-kez`.
5. **Kitap bağlantısı başka kitabınkiyle aynı / eski `kitap/x` adresi** → panel benzersiz bağlantı üretir; `kitaplar/x/y` 404. → Task 2 `kitap-adresleri`.

test('kitap-vitrini', () => {
  const pg = R.page('kitaplar');
  assert.equal(count(pg.html, /class="scard/g), 3);
  assert.match(pg.html, /class="sgrid books"/);
  assert.match(pg.html, /class="sbadge">Ön sipariş</);
  assert.match(pg.html, /3 kitap/);
});
test('kitap-sayfasi', () => {
  const b = S.normalize({}).books[0];
  const pg = R.page('kitaplar/' + b.slug);
  assert.match(pg.html, new RegExp(`<h1[^>]*>${b.title}</h1>`));
  const book = pg.schema.find((n) => n['@type'] === 'Book');
  assert.equal(book.isbn, b.isbn); assert.equal(book.numberOfPages, b.pages);
  assert.equal(book.potentialAction.length, 7);
  assert.equal(book.potentialAction[0]['@type'], 'BuyAction');
  assert.match(pg.html, /class="kunye"/);
});
test('kitap-satin-alma-dugmeleri', () => { // yalnızca gerçek ürün/arama adresleri; hiç yoksa not
  const d = S.normalize({});
  Object.assign(d.books[0], { amazon: 'https://www.amazon.com.tr/', dr: '', kitapyurdu: 'amazon', idefix: '', bkm: '', hepsiburada: '', trendyol: 'https://www.trendyol.com/sr?q=x' });
  const html = Render.create(d, { mode: 'local' }).page('kitaplar/' + d.books[0].slug).html;
  assert.equal(count(html, /class="buybtn/g), 1);
  assert.match(html, /class="buybtn primary"[^>]*>Satın al · Trendyol</);
  d.books[0].trendyol = '';
  assert.match(Render.create(d, { mode: 'local' }).page('kitaplar/' + d.books[0].slug).html, /Yakında satışta/);
});
test('asgari-kitap', () => {
  const d = S.normalize({}); d.books = [{ id: 'a', title: 'Asgari', slug: 'asgari', published: true }];
  const r = Render.create(d, { mode: 'local' });
  for (const route of ['kitaplar', 'kitaplar/asgari']) assert.doesNotMatch(r.page(route).html, /undefined|null|NaN/);
  assert.doesNotMatch(r.page('kitaplar/asgari').html, /class="kunye"/);
});
test('kitap-rotalari-gizli-menu', () => { // gizli menü + yalnızca örnekler: yayında kitaplar sayfası yok
  const site = Render.create(S.forPublish(S.normalize({})), { mode: 'site', siteUrl: 'https://ornek.test/' });
  assert.ok(!site.routes().some((x) => x.startsWith('kitaplar')));
  const d = S.normalize({}); d.books.push({ id: 'k', title: 'Kendi', slug: 'kendi', published: true });
  const r2 = Render.create(S.forPublish(d), { mode: 'site', siteUrl: 'https://ornek.test/' });
  assert.ok(r2.routes().includes('kitaplar') && r2.routes().includes('kitaplar/kendi'));
  assert.doesNotMatch(r2.navLinks(), /kitaplar/); // menüde gizli
});
test('kitap-adresleri', () => {
  assert.equal(R.page('kitaplar/yok/olmaz').status, 404);
  assert.equal(R.page('kitaplar/yok').status, 404);
  assert.ok(R.searchIndex().some((i) => i.label === 'Kitap'));
});
